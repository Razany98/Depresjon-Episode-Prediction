# Predicting Psychiatric Flare-Ups from Wearable Activity Data

This project explores the use of wearable actigraphy data and machine learning for predicting psychiatric flare-ups using temporal behavioral signals.


Using the Depresjon dataset, the system analyzes changes in movement behavior, circadian rhythm instability, nighttime activity, and rolling behavioral trends to detect potential depressive or manic episode emergence.


Unlike traditional psychiatric classification systems, this project focuses on forecasting future behavioral instability from longitudinal time-series wearable data.

## **Dataset:**

The project uses the publicly available Depresjon Dataset, which contains minute-level motor activity recordings collected from:
- Bipolar disorder patients
- Unipolar depression patients
- Healthy controls
using wrist-worn activity sensors.


The dataset was collected by researchers affiliated with:
- SINTEF Digital
- Haukeland University Hospital
- University of Bergen
- University of Oslo

## **Project Workflow:**

1. **Data Preprocessing:**
- Loaded multiple activity CSV files
- Converted timestamps into datetime format
- Removed invalid activity values
- Sorted records chronologically
- Applied signal smoothing to reduce sensor noise

2. **Temporal Feature Engineering :**
Extracted behavioral and temporal features including:
Rolling activity averages
Activity variability
Short-term behavioral trends
Nighttime movement intensity
Circadian instability indicators

3. **Flare-Up Label Generation:**
Dynamic flare-up labels were generated by comparing short-term activity behavior against patient-specific baseline movement patterns.

4. **Machine Learning:**
The system used:
Random Forest Classifier
SMOTE for class imbalance handling
Probability threshold optimization
Feature importance analysis

## **Results:**

The model achieved very strong predictive performance:
- ROC-AUC Score: 0.986
- High flare-up detection capability
- Strong separation between stable and unstable behavioral periods
The results suggest that wearable movement behavior alone contains highly informative temporal signals associated with psychiatric instability.

## **Most Important Predictive Features:**

The strongest predictive signals included:
- Rolling behavioral variability
- Nighttime activity patterns
- Short-term activity trends
- Circadian instability
Feature importance analysis revealed that temporal behavioral changes were highly associated with flare-up emergence.
